# Mis XV · Lucía

Invitación digital para los quince de Lucía. Es una página corta, pensada para el celular, en azul noche y plateado.

Sábado 23 de enero de 2027, a las 21:30 hs, en el Centro de Jubilados Mi Refugio, Blandengues N° 189, Lezama.

## Cómo verla

```bash
npm install
npm run dev
```

Abrí [http://localhost:4179](http://localhost:4179). En el celular ocupa toda la pantalla. En una computadora queda centrada, del ancho de un teléfono.

La primera pantalla es un sello. Tocá **Abrir invitación** para ver la fecha, la cuenta regresiva, el mensaje de Lucía, el lugar y los botones para llamar o escribir por WhatsApp.
